# Download and Installation

__degrotesque__ is a [Python](https://www.python.org/) script. To run it, you must have [Python](https://www.python.org/) installed. If you have not installed [Python](https://www.python.org/), yet, please read instructions on installing [Python](https://www.python.org/) first (see below).


## Installing degrotesque

The current version is [degrotesque-3.0.0](https://github.com/dkrajzew/degrotesque/releases/tag/3.0.0).

You have different options for installing __degrotesque__.

### Installing from PyPi

You may __install degrotesque__ using

```console
python -m pip install degrotesque
```

You may consider building a virtual environment, first.

You may then run __degrotesque__ using 

```console
degrotesque
```

This will install __degrotesque__ as a script that may be directly called on the command line as well as the [Python](https://www.python.org/) module which you may import using ```import degrotesque```. The PyPi version only includes the (executable) source code and files needed to run it.

### Cloning the repository

You may __clone the repository__ which is available at [degrotesque&apos;s github page](https://github.com/dkrajzew/degrotesque).

```console
git clone https://github.com/dkrajzew/degrotesque.git
cd degrotesque
```

You may then run __degrotesque__ using 

```console
python degrotesque/degrotesque.py
```

Please note that the current repository version may contain an in-between version with new, undescribed, or even buggy behaviour. You should rather use a recent version.

### Download the latest release

Besides, you may __download the current release__ here:

* [degrotesque-3.0.0.zip](https://github.com/dkrajzew/degrotesque/archive/refs/tags/3.0.0.zip)
* [degrotesque-3.0.0.tar.gz](https://github.com/dkrajzew/degrotesque/archive/refs/tags/3.0.0.tar.gz)

You will get the complete copy of the repository which you have to decompress. A folder named ```degrotesque-3.0.0``` will be generated. __degrotesque.py__ is stored in the ```degrotesque``` folder.

You may run __degrotesque__ using 

```console
python degrotesque/degrotesque.py
```


## Installing Python

[Python](https://www.python.org/) is an interpreted programming language. For running __degrotesque__ and other scripts written in Python you have to install [Python](https://www.python.org/) itself, first.

For installing [Python](https://www.python.org/), use an installer for your system from <https://www.python.org>.

You should as well install **pip**, a package manager for [Python](https://www.python.org/). After installing [Python](https://www.python.org/), you should be able to install **pip** using:

```console
python get-pip.py
```

You may upgrade pip using:

```console
pip install --upgrade pip
```
